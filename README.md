# varunbharadwaj portfolio

Static site: one `index.html`, photos next to it in the root folder, CV as a PDF. No build step.

- To change text, edit `index.html`.
- To swap a photo, replace the file with one of the same name, or add a new file and point the `src` in `index.html` to it.
- To update the CV, upload a new `Varun_Bharadwaj_CV.pdf` with the same name.

GitHub Pages serves this from the `main` branch, root folder.
